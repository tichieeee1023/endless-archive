# 종점 없는 서고

끝나지 않은 이야기들을 싣고 달리는 열차. 여행자는 객차마다 다른 이야기를 만나고, 선택을 통해 라엘·세온·카이루와 인연을 쌓습니다.

## 실행하기

Node.js를 설치한 뒤 프로젝트 폴더에서 실행합니다. PowerShell 실행 정책이 `npm.ps1`을 막는 환경에서는 아래처럼 `npm.cmd`를 사용하세요.

```powershell
npm.cmd install
npm.cmd run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 엽니다.

## 여정

- 새 여정을 시작하면 프롤로그와 첫 선택을 만납니다. 건너뛰기를 누르면 첫 선택으로 바로 이동합니다.
- 페이지를 선택할 때 만남과 이야기, 전투, 휴식, 상점 등의 기회를 고를 수 있습니다. 한 인물과 쌓은 관계는 후속 장면을 열고 전투에서 받는 피해를 줄입니다.
- 전투 화면의 자동 전투를 켜면 상황을 보고 행동합니다: 한 번에 쓰러뜨릴 수 있으면 곧바로 공격하고, 마지막 장의 강공격 예고에는 흘려내기를 쓰며, 집중 공격이 기본 공격보다 강할 때만 집중 공격을 씁니다. 체력 물약은 다음 반격에 쓰러질 수 있을 때만 마십니다. 물약은 턴을 소모하지 않습니다. 끄면 직접 선택할 수 있습니다.
- 관계와 플래그는 한 번의 여정에 적용됩니다. 모은 엔딩과 서고 기록은 새 여정을 시작해도 남습니다.
- 서고에서 엔딩을 다시 읽고 저장 슬롯을 전환할 수 있습니다. 시드를 공유하면 같은 페이지 구성을 만날 수 있지만, 조우와 판정은 매번 달라집니다.

기존 저장 중인 여정은 그대로 이어지며, 새 프롤로그는 새 여정부터 시작합니다.

## 주요 파일

- `src/data/prologue.ts` — 프롤로그와 첫 선택
- `src/data/encounters.ts`, `src/data/memories.ts` — 인물 및 이야기 조우
- `src/lib/ending.ts` — 관계와 선택에 따른 결말
- `src/store/useRun.ts` — 여정 진행과 저장
- `src/assets/illustrations/` — 인물과 배경 펜화

## 확인 명령

```powershell
npm.cmd run build
npm.cmd run lint
npm.cmd run sim
npm.cmd run test:balance
npm.cmd run test:art
```

시뮬레이션은 실제 게임 규칙과 자동 전투 판단을 사용합니다. `node scripts/simulate.mjs 600 orig`는 사건 우선, `hybrid`는 혼합, `grind`는 전투 우선 전략입니다. 진실 엔딩은 이름 없는 역의 현재 여정 단서로 판정합니다. 결과는 실제 플레이어 행동과 다를 수 있습니다.

## 스토리 중심 밸런스 패치

- 호감도 8 이상이면 중간 패배에서 한 여정당 한 번 구조됩니다. 체력 40%로 회복, 골드 절반 손실, 전투 보상 없음.
- 최종 보스 패배에서 호감도 12 이상이면 가장 가까운 인물의 구원 엔딩으로 이어집니다. 동률일 경우 라엘, 세온, 카이루 순입니다. 연애 여부 및 중간 구조 사용 여부와 무관합니다.
- 기존 인물 사건과 관계 보너스를 그대로 기록합니다. 구원 엔딩은 사망/클리어와 별도 통계로 집계합니다.
- 여정 저장 버전 13 및 기존 저장 키를 유지합니다. 이미 진행 중인 전투의 적 수치와 주사위 결과는 보존되며 새 전투부터 새 보스 수치가 적용됩니다.
- 상세 변경·검증 및 환경 제한은 `BALANCE_PATCH_REPORT.md`를 참조하세요.


## 인물 서사 확장
- 신규 인물 장면 27개와 선택형 재회(3·6·7층), 관계별 대사, 최종 보스 직전 지원을 추가했습니다. 신규 그림 대신 기존 스탠딩을 사용합니다.
- `npm run test:companions`는 기존 회귀와 신규 테스트를 함께 실행합니다. `COMPANION_EXPANSION_REPORT.md`에서 변경 내용과 검증 한계, 향후 CG 목록을 확인하세요.
