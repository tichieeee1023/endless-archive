# 종점 없는 서고

끝나지 않은 이야기들을 싣고 달리는 열차. 여행자는 객차마다 다른 이야기를 만나고, 선택을 통해 라엘·세온·카이루와 인연을 쌓습니다.

## 실행하기

Node.js를 설치한 뒤 프로젝트 폴더에서 실행합니다. PowerShell 실행 정책이 `npm.ps1`을 막는 환경에서는 아래처럼 `npm.cmd`를 사용하세요.

```powershell
npm.cmd install
npm.cmd run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 엽니다.

## 여정

- 새 여정을 시작하면 프롤로그와 첫 선택을 만납니다. 건너뛰기를 누르면 첫 선택으로 바로 이동합니다.
- 페이지를 선택할 때 만남과 이야기, 전투, 휴식, 상점 등의 기회를 고를 수 있습니다. 한 인물과 쌓은 관계는 후속 장면을 열고 전투에서 받는 피해를 줄입니다.
- 전투 화면의 자동 전투를 켜면 내공이 있을 때 무공을 사용하고, 없으면 기본 공격을 합니다. 끄면 직접 선택할 수 있습니다.
- 관계와 플래그는 한 번의 여정에 적용됩니다. 모은 엔딩과 서고 기록은 새 여정을 시작해도 남습니다.
- 서고에서 엔딩을 다시 읽고 저장 슬롯을 전환할 수 있습니다. 시드를 공유하면 같은 페이지 구성을 만날 수 있지만, 조우와 판정은 매번 달라집니다.

기존 저장 중인 여정은 그대로 이어지며, 새 프롤로그는 새 여정부터 시작합니다.

## 주요 파일

- `src/data/prologue.ts` — 프롤로그와 첫 선택
- `src/data/encounters.ts`, `src/data/memories.ts` — 인물 및 이야기 조우
- `src/lib/ending.ts` — 관계와 선택에 따른 결말
- `src/store/useRun.ts` — 여정 진행과 저장
- `src/assets/illustrations/` — 인물과 배경 펜화

## 확인 명령

```powershell
npm.cmd run build
npm.cmd run lint
npm.cmd run sim
```

시뮬레이션은 실제 게임 규칙을 사용해 만남과 회복을 우선하고 자동 전투와 감응 투자를 택하는 한 가지 전략을 실행합니다. 결과는 선택과 무작위 조우에 따라 달라지며, 이전 여정의 엔딩 기록이 필요한 진실 엔딩은 계산하지 않습니다.
